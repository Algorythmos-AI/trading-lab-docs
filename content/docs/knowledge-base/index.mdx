## What it is

One private repository of sources, page extracts and claim cards. Each claim is checked by a second reader
before it counts. A platform uses it by pinning a tagged release and citing claims by id.

## Pipeline

The tooling is standard-library Python with one local gate; the repository runs no automated checks online.
