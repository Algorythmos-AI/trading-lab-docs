## What code cannot close

F2, F3, F4 and F6 need days or weeks of real operation. Writing more code does not move them.

## Decisions still to be written

## The order of work from here

1. Done on 2026-10-12: the float is funded and the recorder and trader have run from a laptop, every sleeve
   in shadow. Open: the reconciliation break that followed a gateway reconnection.
2. After one clean trading day the control sleeve places minimum-size paper orders in two pairs; the other
   two pairs stay on the shadow venue.
3. Five such days with zero reconciliation breaks: the F4 gate. Five recorded days: the F2 and F3 gates.
4. The access-route record is written, once an order timing is taken on the server.
5. Pre-flight day on the host, then the install, so it runs unattended.
6. Strategies and the weekly learning loop on real recordings.
