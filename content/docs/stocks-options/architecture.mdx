interest.

## Layers

| Layer | Packages | Rule |
|---|---|---|
| Core | `core` | The paper lock, the clock and the ledgers; everything else depends on it |
| Research | `data`, `scanner`, `signals`, `backtest`, `research` | No broker calls |
| Trading | `risk`, `oms`, `brokers`, `live` | The only path that can place an order |
| Options | `options` | Reads; never trades |
| Operations | `ops`, `analytics` | Runs jobs, gates deploys, publishes status |

## Design choices

- **One clock.** All session logic runs in New York time, in one module.
- **Causal by construction.** Features and signals may only read what was known at that moment; tests check it.
- **Runtime state outside the checkout.** A deploy cannot disturb a running job's state.
- **Every job through one runner.** Lock, pre-flight, deadline, heartbeat.
- **A desk is a record.** Each desk declares its own limits, state and keys, so desks cannot reach into each
  other.
- **The schedule is code.** Service units are generated from the job table; see
  [facts and register](/stocks-options/facts).

## How status leaves

A job collects state, keeps only allowlisted fields, signs the result and pushes it. See
[the status site](/shared/status-site).
