Three things are shared on purpose. Everything else belongs to one platform.

## The cloud server

- One Linux virtual machine in the cloud runs every scheduled job.
- Each platform has its own user or unit prefix, its own checkout, its own state folder and its own secrets
  file.
- Jobs are service units generated from code, so the schedule in the repository is the schedule on the host.
- The Mac runs nothing.

## Deploys

- The owner deploys by hand only what the server will not take by itself: a change to the deploy machinery.
- A deploy gate decides whether it may proceed: required checks passed on that commit, and no market session
  in progress.
- A rollback is one command.
- The server deploys itself: once an hour it takes the newest green release on `main` when the gate is open.
  A release that changes the deploy machinery itself waits for the owner to deploy it by hand.
