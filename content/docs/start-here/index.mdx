## Repositories

| Repository | Platform | Role |

## How they connect

<PlatformMap />

- **Each platform is one repository** with its own configuration, kill switch, state, journal, secrets file,
  runbooks and deploy units.
- **Nothing is imported across platforms.** Knowledge is shared through a tagged release a platform pins; today
  only Forex HFT pins one. Status is shared through a versioned snapshot format that the status site checks by
  hash.
- **The host pushes; the status site never pulls.** A snapshot is built from an allowlist, signed, and sent.

## Shared on purpose

One cloud server, one status site, and the knowledge base. Today only Stocks & Options runs on the server and
reports to the site. Everything else is separate.

The catalog of every repository is `catalog.yaml` in `algorythmos-handbook`; [Repositories](/shared/repositories)
is generated from it.
