---
title: Glossary
description: The words these pages use, in one place.
---

| Term | Meaning |
|---|---|
| Paper trading | Orders on a simulated account. No real money moves. |
| Desk | One market traded by one set of jobs, with its own limits and state. |
| Gate | A written test a platform must pass before the next stage. |
| Phase | A stage of a platform's build. Forex HFT uses F0 to F7; the options workstation uses P0 to P6. |
| Sleeve | One strategy slot on a desk, with its own limits and its own record. |
| Shadow | A sleeve or model that decides but places no order; its decisions are recorded for comparison. |
| Challenger | A variant run in shadow against the current choice. |
| Champion | The model or rule currently in use. |
| Promotion | Moving a challenger into use, by a rule written in advance. |
| Snapshot | A signed status document a platform sends to the status site. |
| Contract | The versioned format of a snapshot. |
| Kill switch | Stops new entries; exits continue. |
| Latch | A risk stop that stays on until someone resets it. |
| Cutover | Moving a running desk from one checkout to another on the host. |
| Design record | A short dated document that records one decision and why. Also called an ADR. |
| Runbook | Step-by-step instructions for one operation or one incident. |
| R | Result measured in units of the risk taken on the trade. |
